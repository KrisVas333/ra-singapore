The problem

Parents want robotics and AI classes. Building them from zero takes years.

  • No ready curriculum. Writing 40 weeks of lessons for ages 3 to 12 is a full-time job.

  • Hard to staff. Teachers need training before they can run a robotics class.

  • Kits gather dust. A box of robots alone doesn't keep kids coming back.

We learned it from a robot in a drawer.

Kris's younger brother got a LEGO robot from America. Two weeks later it was in a drawer.

A kit alone doesn't teach. Kids need a mentor, a group and a goal. That's what we built.

The solution

Small groups. Real robots. One path from age 3 to AI.

Real lessons in Lithuania.

  1. 3–4

    Screen-free robots

    Matata coding robots and story cards. No screens.

  2. 5–6

    First robotics

    LEGO Education: build, add a motor, program it. 60 min, up to 10 kids.

  3. 7–10

    Robotics & coding

    Sensors, algorithms, bigger builds. 90 min a week, up to 14 kids.

  4. 7–10

    Game Creators

    Minecraft Education: build worlds, code logic, first steps with AI.

  5. 8–12

    BrainClub

    AI, VR and how your own attention works.

Singapore

We're new here. So we start with a pilot.

We don't run any Singapore classes yet. We want a few first partner centres for one pilot term, and we'll set the terms together.

The pilot in six lines

  • You: an enrichment centre or school with kids aged 3 to 12
  • You: a room, a weekly slot and one person who wants to lead it
  • You: honest feedback every month
  • Us: the curriculum and mentor training
  • Us: kit list, room setup help and ExoClass for sign-ups and payments
  • Us: the founders on email and calls during the pilot

Children's data. In Singapore we will work under the PDPA: a parent consents before we collect anything about a child, we keep only what's needed to run the class, and no child's photo is used without written parental consent.

MOE. Our instructors aren't MOE-registered yet, and we don't claim MOE alignment. If you run classes in MOE schools, we'll plan instructor registration with you.
